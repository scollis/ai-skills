# AODBE - Aerosol Optical Depth Best Estimate

The AODBE VAP combines aerosol optical depth measurements from four collocated ground-based instruments (two MFRSRs, NIMFR, and CSPHOT) at the ARM SGP observatory into a single quality-screened, high-temporal-resolution best-estimate AOD product at 500/870 nm (AODBE2CH) or five wavelengths (AODBE5CH).

A **value-added product**: ARM computes it from instrument data rather than measuring it.
Facts below are marked with their source - the technical report (`tr p. N`, 22 pages),
ARM's catalog, or the example file under **The data**, which was opened rather than assumed.

## How it is produced

The combined (best-estimate) AOD is generated by retrieving AOD measurements from four input sources (MFRSR C1, MFRSR E13, NIMFR, and CSPHOT/AERONET) at 500 and 870 nm (AODBE2CH) or five wavelengths (AODBE5CH). Each individual AOD measurement is averaged to a 1-minute time scale, excluding any time sample with a non-zero QC value or an AOD value outside the range 0 to 1. For each minute, the combined AOD is calculated as the average of the 1-min averaged inputs that have a good (zero) QC value, so the number of contributing sources for a given minute can range from 2 to 4; if none are good, the combined AOD is set to the missing value (-9999). Uncertainty of the combined AOD is characterized by the standard deviation of the contributing points (or a standard value of 0.02 when only one input is used) and by the range (max-min) of the inputs used.

**Cadence.** input rate instrument-dependent (varies by MFRSR, NIMFR, CSPHOT source); output every 1-min combined AOD; daily-averaged AOD also produced for analysis; averaging Each AOD measurement averaged to 1-min scale (0 s inclusive to 60 s exclusive); combined AOD is average of good-QC 1-min inputs from up to 4 sources (hb p. 2).

## Inputs

The report names these instruments and sibling products: MFRSR (Multifilter Rotating Shadowband Radiometer), NIMFR (Normal Incidence Multifilter Radiometer), CSPHOT (Cimel Sunphotometer), AERONET.

A VAP inherits every limitation of its inputs. When a retrieved value looks wrong, check
the input instrument's own skill (`arm-instrument-<code>`) and its DQRs before concluding
the algorithm is at fault; the reverse is rarer.

## Quality control in this product

25 `qc_` companion variables cover 25 of the
108 data variables. Assessments present in the example file: `Bad`, `Indeterminate`.

A VAP's QC flags describe the retrieval, not the instrument: a value flagged here may
mean the algorithm refused to converge, or that an input was missing, rather than that
the sensor misbehaved. Read `flag_meanings` before interpreting a filtered series.

act_qc_table(ds)                       # what each bit would remove, per variable

The report's own note on quality: AODs from ARM-supported instruments (MFRSR C1, MFRSR E13, NIMFR) incorporate automated QC tests; only data flagged 'good' (QC value of zero) are used in generating the combined AOD. CSPHOT data used are 'quality-assured' (Level 2.0) from AERONET Version 3, which has improved cloud screening compared to its predecessor. During 1-min averaging, samples are excluded if they have a non-zero QC value or an AOD value less than 0 or greater than 1. The VAP also computes daily linear regression statistics (R2, slope, mean bias, N) for six pairs of the four input AODs, and a StDv (standard deviation)...

## Documented failure modes

From the technical report. For a derived product these are mostly conditions where the
retrieval is invalid, biased, or silently falls back - read this before concluding that
a feature in the output is atmospheric.

| issue | how it shows up | what the report says to do | source |
|---|---|---|---|
| Unscreened 'incorrect' NIMFR AOD values passing automated QC | NIMFR AODs substantially exceed those from the other three instruments and show weak spectral dependence (e.g., summer of 2003); shows up as occasional 'incorrect' spikes in the combined... | Apply a StDv threshold (e.g., 0.01) to screen out days with inconsistent/incorrect AODs; automated QC tests alone are insufficient | (hb p. 6) |
| Cloud contamination of NIMFR AOD | AOD values are anomalously high with weak spectral dependence | None specified beyond general StDv screening | (hb p. 6) |
| Data gaps in individual instrument time series | Detached/missing segments in AOD time series, duration from several weeks to several months (NIMFR gaps up to several years) | Combined AOD merges available individual AODs to improve continuity, though filling gaps with unavailable individual AODs is not considered | (hb p. 6) |
| NIMFR record has longest and most numerous gaps | NIMFR AOD time series shows many detached parts compared to MFRSR and CSPHOT records | None specified | (hb p. 6) |
| Resolution/quality mismatch between input AOD products | Instrument-dependent continuity, quality, and resolution of AOD products differ across MFRSR, NIMFR, CSPHOT | AODBE algorithm merges only good-QC values and computes combined AOD/uncertainty to address mismatch | (hb p. 1) |
| Small sample size for pairs involving CSPHOT | N ≤ 44 for MFRSR/NIMFR vs CSPHOT pairs versus N ≤ 438 for MFRSR-MFRSR/MFRSR-NIMFR pairs, contributing to slope differences (~0.8 vs ~1.0) | None specified beyond noting the sample-size effect | (hb p. 9) |
| Large StDv (greater than 0.05) of combined AOD | Rare events (~3% of time) representing days with occasional incorrect AODs, visible as outliers in Figure 2/4 | Choose an appropriate StDv threshold (e.g., 0.01) to eliminate such days while preserving seasonal pattern | (hb p. 10) |
| Reduced temporal coverage relative to combined product | Coverage of combined AOD substantially greater than NIMFR AOD (~80% difference) and CSPHOT AOD (~40% difference), due to large gaps and partial overlaps among instruments | None specified | (hb p. 11) |
| CSPHOT/AERONET operation and scheduling differs from ARM-supported radiometers | Different data availability/continuity pattern for CSPHOT compared to MFRSR/NIMFR | Use quality-assured (Level 2.0) AERONET Version 3 data with improved cloud screening | (hb p. 1) |
| Missing value flag | Combined or averaged AOD set to -9999 when no valid/good time samples exist for a given minute | None specified beyond flagging as missing | (hb p. 3) |
